**第 28 集 · ALS-XZ**（`als_xz`）完整口播
「数独不用猜。今天跟我一起学数独高级技巧——**ALS-XZ**：两个『差一数集』，靠公共数字 X 搭桥，把目标数字 Z 从盘面上删掉。」

「先认识 ALS——几乎锁定集：n 个格子，候选总共只有 n+1 个数字，就差一个数就能锁定。比如三格候选合起来只有 {1,2,4,6}。  
关键性质：这 n 格里必有一个格子要填 X——因为 X 是候选之一，躲不掉。  
现在找两个 ALS，它们各自都含数字 Z，还共享一个数字 X，而且 X 在两边都被限制——一个 ALS 填 X，另一个的 X 就被挤掉。  
两边的 X 不能同时成立？不——推下去：如果两边都不出 Z……用 X 一搭桥就会矛盾。  
结论：Z 必定出现在其中一个 ALS 的某个格子里。  
于是同时看到两组 Z 落点的格子，不能放 Z。」

看盘面：ALS 甲三格含 Z=5，ALS 乙两格也含 5，公共数字 X=2 相连。  
同时看到两组 5 落点的 r4c6，候选 5 标红删除。

ALS-XZ 是 ALS 家族的入门招：认住『格数比候选数少一』，再找 X 和 Z 两个角色。

下面一起练习两题
第一题：找出两个 ALS 和公共数 X，再删共同可见格的目标数 Z。
第二题：换一组 ALS，先验证 X 被限制的位置再删数。

好了总结一下，
「记住口诀：**两组格子各差一数，公共数字X搭桥；齐看两组Z落点，此数必删。**
ALS 就是『多一格的数组』，桥一搭就开删。」
