**Episode 7 · Pointing Pairs & Box/Line Reduction** (`pointing_pair`) — Full voice-over script

No guessing in Sudoku. Intermediate — **Pointing Pairs** (and **Box/Line Reduction**). Two mirror cases: box-to-line, and line-to-box.

**Box → line (Pointing Pair):**  
In a box, every place a digit can go lies on **one** row or **one** column.  
That digit is locked to that line inside the box — so **outside** the box, on that same line, delete the digit.

Name it this way: the box **points** the digit along a row or column.

Top-left box: all cells that can still be **8** are green and sit on row 1.  
So 8 in this box is confined to row 1.  
Any **8** candidate on row 1 **outside** this box gets eliminated.

Same for columns: if all placements in a box sit on one column, eliminate that digit outside the box on that column.

Practice: in this box, 8’s placements fall on one column — wipe 8 outside the box on that column.

---

**Line → box (Box/Line Reduction):**  
In a row or column, every cell that can still hold a digit sits in **one** box.  
That line **claims** the digit for that box — delete it from **other** cells in the box.

Mirror image:  
Box → line: the box points outward.  
Line → box: the line claims inward.

Row 4: green cells for **9** all lie in the center box.  
Row 4 assigns 9 to that box.  
Remove 9 from r5c6 and r6c4 in the center box.

Column-to-box works the same.

Practice: find line-to-box, then column-to-box — don’t reverse the direction.

Homework or app — five correct in a row.

**Mnemonics:**  
**Digits in the box line up on one row/column — delete that digit outside the box on that line.**  
**Digits on a line pile into one box — delete that digit elsewhere in the box.**
