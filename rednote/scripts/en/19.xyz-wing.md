**Episode 19 · XYZ-Wing** (`xyz_wing`) — Full voice-over script

No guessing in Sudoku. Advanced — **XYZ-Wing**: pivot holds **three** candidates X, Y, Z; wings stay bivalue **XZ** and **YZ**. Cells in the same house that see both wings cannot be **Z**.

Same logic as XY-Wing: pivot X → XZ wing commits Z; pivot Y → YZ wing commits Z; pivot Z directly — one of the three must be Z.  
Any cell seeing all three cells in the pattern (usually same box or line) drops Z.

On the board: pivot r5c5 {3,6,9}, wings r5c4 {3,9} and r4c6 {6,9}; r5c6 sees the set — delete 9.

Difference in one line: XY pivot excludes Z (wider eliminations possible); XYZ pivot includes Z (tighter visibility rules).

Practice; compare to an XY-Wing example.

Homework or app.

**Mnemonic: Pivot XYZ, wings each miss one digit — where all three are visible, Z goes away.**
