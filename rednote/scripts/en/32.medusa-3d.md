**Episode 32 · 3D Medusa** (`medusa_3d`) — Full voice-over script

No guessing in Sudoku. Advanced — **3D Medusa**: Simple Coloring for **all digits** — strong links and bivalue cells colored together; conflicts in 3D eliminate candidates.

Single-digit coloring alternates true/false on strong links.  
Medusa colors **candidate–cell** nodes: in a bivalue cell, one candidate green, one yellow — mutually exclusive.  
Rules: same color sees itself in a house → color false; one cell, same color on two candidates → that color false; same digit, same color twice in a house → color false.

On the board: multi-digit coloring; two green 7s in box 6 → green false; cascades to placements.

Mark “digit + color” as you go.

Practice color contradictions.

Homework or app.

**Mnemonic: Color all strong links — peer same color kills the color; one cell double same color kills the color.**
