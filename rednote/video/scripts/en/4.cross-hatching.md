**Episode 4 · Cross-Hatching** (`scanning`) — Full voice-over script

No guessing in Sudoku. Today’s beginner technique — **Cross-Hatching**: choose a digit, cross off rows and columns that already contain it, then see where it can still go in a box.

Cross-hatching is the most common, most reliable scan in Sudoku:  
pick digit **d**, then in a row, column, or box, find the **only** cell that can still hold **d**.  
You’ll use it with Full House and Hidden Singles — especially when you’re tracking where a digit can go inside a box.

Think of it as the **hands-on method** for finding Hidden Singles.

On this board, hunt **6** in box 1.  
Row 2 already has 6 — rule out row 2.  
Column 2 has 6 — rule out column 2.  
Column 3 has 6 — rule out column 3.  
Only the top-left green cell in box 1 can take **6**.

One scan, one Hidden Single.

**How to find it:** pick digit **d** → cross off lines that already contain **d** → see what’s left in each box.
