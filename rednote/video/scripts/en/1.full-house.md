No guessing in Sudoku. Today we start with a beginner technique — **Full House**: when a row, column, or box has only one empty cell, the answer is fixed.

**Visual:** Board opens; one box has a single blank; on-screen title “Full House”.

One rule: if a row, column, or 3×3 box already has eight digits and only **one** blank, that blank must be the **missing** digit.  
That’s Full House.

Look at the center box —  
it already has 1, 2, 3, 4, 5, 6, 7, and 9. Only r5c5 is empty.  
The missing digit is **8**.

Same logic on a **row**. Row 2 has only r2c5 empty — again, that cell must be **8**.  
Columns work the same: one empty in a column, fill what’s missing.

Scan order to remember: check every **box**, then every **row**, then every **column**.
