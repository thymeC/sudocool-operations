**Episode 3 · Hidden Single** (`hidden_single`) — Full voice-over script

No guessing in Sudoku. Today’s beginner technique — **Hidden Single**: pick a digit and ask where it can still go in a row, column, or box. If only one cell remains, that’s the answer.

**Naked Single** looks **at the cell** — what can fit here?  
**Hidden Single** looks **at the digit** — where can this number still go?

In a house, cross off every cell that already has the digit or cannot take it.  
If one empty cell is left, that cell must take the digit.

Example: in box 1, digit **6** can only land in the top-left green cell — every other cell in the box is ruled out by peers.  
That’s a Hidden Single.

You’ll use this constantly. **Cross-hatching** in the next episode is basically practice for spotting Hidden Singles fast.

Practice in the app — five in a row means you’ve got it.

**Takeaway:** Follow the digit — one landing spot left → fill it.  
**Mnemonic:** Naked Single watches the cell; Hidden Single watches the number.
